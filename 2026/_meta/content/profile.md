## About

I'm Ming, a **Software Architect**, **AI Engineer** with **20+ years** of experience building large scale software systems. I'm also a **Content Creator** who makes AI engineering related (**250+**) videos for knowledge sharing.

Recently, I've been applying that experience to **AI coding**, **agent systems** and **automation** - building practical ways to keep AI-assisted systems scalable, reliable and maintainable as they grow.

My current focus is converting that experience into **shareable skills** - reusable, proven practices that let others benefit without repeating the same work.

### Focus areas

- **Harness Engineering for Coding** — A small requirement shouldn't cause LLM to make widespread code and test changes. I structure code so responsibilities, implementation variants and their tests remain isolated. _(**Keep AI code changes isolated**)_
- **Skill Optimisation** — Quality, reliability, speed and cost shouldn't depend solely on whether an agent follows its instructions. I built an execution harnesses that enforce the process around it. _(**Make agent execution reliable**)_
- **AI Automation** — Large automation systems shouldn't become fragile because the UI they operate against changes. I created a solution that allows LLM to operate with minimum changes. _(**Make automation survive change**)_
